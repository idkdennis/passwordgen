# Password Generator

A simple Python program that creates random secure passwords.

## What It Does

This program asks you how many numbers, letters, and symbols you want in your password, then creates a random password for you.

## How to Use

1. Run the program
2. Enter how many numbers you want
3. Enter how many letters you want  
4. Enter how many symbols you want
5. Get your random password!

Example:
```
how many numbers do you want in your password: 4
how many letters do you want in your password: 8
how many symbols do you want in your password: 3

Your password: aB4#c2D!e1F@g3H
```
